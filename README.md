# FORKT-HUB V3

Utility controller for **Violence District**, built with WindUI.

## Features

### ESP
- Killer ESP
- Killer Chams
- Automatic killer visual updates
- ESP visual cleanup when disabled
- Optimized ESP refresh loop

### Combat
- Auto Parry
- Automatic killer attack-animation detection
- Parry range control
- Killer-facing requirement
- Facing sensitivity detection
- Parry debounce control
- Parry lead timing
- Automatic parry input handling
- Automatic parry remote detection

### Skills
- Auto Skill Check
- Skill-check rotation detection
- Automatic Space input
- Skill-check execution protection

### Visual
- Fullbright / Night Vision
- Camera FOV control
- Custom FOV slider
- Restore default FOV

### Interface
- WindUI interface
- Organized sections:
  - Core
  - Combat
  - Utility
  - Interface
- Overview dashboard
- ESP tab
- Parry tab
- Skills tab
- Visual tab
- Settings tab
- UI theme selector
- Mobile buttons
- Right Shift toggle key
- Clear All Visuals
- Unload FORKT-HUB V3

### System
- Duplicate-execution protection
- Automatic cleanup of previous UI
- Automatic cleanup of previous ESP and Chams
- Connection lifecycle management
- Character respawn handling
- Team-change handling
- Safe shutdown system
- Performance-optimized visual updates
- Cleanup protection against duplicated visuals and connections
